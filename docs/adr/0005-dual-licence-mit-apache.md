# ADR-0005: MIT OR Apache-2.0 双许可

**状态**: 已接受（2026-10-02）
**来源**: `docs/DESIGN.md` 决策 31

## 背景

开源项目将发布到 GitHub。候选：单 MIT、单 Apache-2.0、双许可。

## 决策

**`MIT OR Apache-2.0` 双许可**（Rust 生态事实标准，`cargo` / `rustc` / `serde` 均如此）。

## 后果

- 用户与贡献者**不需要思考**该用哪个——可以任选其一。
- 同时给出 MIT 的简洁与 Apache 的**显式专利授权**。
- 对一个"下载并执行第三方二进制"的工具，专利与责任条款不是形式主义。
- 仓库根需同时放 `LICENSE-MIT` 与 `LICENSE-APACHE`（已就位）。
- **一个连带约束**：`slint` 因此出局（唯一免费档是 GPLv3），GUI 选型必须避开 GPL-only 的依赖。

## 被否决的方案

- **单 MIT**：缺显式专利授权。
- **单 Apache-2.0**：部分用户嫌它"法务味重"，且与生态惯例不一致。
